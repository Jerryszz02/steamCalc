# PRD：Steam 史低计算器

## 文档目的

定义「Steam 史低计算器」当前已经实现、且后续改动不得意外破坏的产品行为，作为验收依据。本文档从仓库代码（`index.html`、`app.js`、`api.js`）逆向整理，描述的是现状而非规划。

## 适用范围

- 适用：浏览器中运行的全部用户可见行为，包括搜索、价格详情、史低判定、区域切换、愿望单、API key 设置。
- 不适用：实现细节（见 `technical-design.md`）、部署运维（见 `technical-design.md` 部署章节）。

## Plan 或项目证据

- `README.md`：功能清单与数据源说明。
- `app.js`：`computeVerdict` 判定规则、`doSearch`/`showDetail`/`refreshWishlistPrices` 等行为函数、`REGIONS` 区域表、`updateSourceHint` 数据源切换逻辑。
- `index.html`：页面各区结构与设置 dialog 文案。

## 背景与问题定义

Steam 打折频繁，用户想知道某个游戏「现在的价格是不是历史最低、值不值得买」。本工具输入游戏名，对比当前价与史低价，直接给出结论，并支持把游戏加入本地愿望单持续跟踪。

目标用户：想挑时机买 Steam 游戏的个人玩家，尤其是关注国区等多区价格的中文用户。

## 功能需求

### 1. 游戏搜索

- 输入游戏名（如 `Stardew Valley`）提交后展示候选列表，最多 10 条。
- 数据源二选一，由是否填写 ITAD API key 决定：
  - 已填 key：走 IsThereAnyDeal（ITAD），结果显示游戏标题和类型标签。
  - 未填 key：走 CheapShark 兜底，结果显示缩略图、标题和全网最低价（美元）。
- 搜索中显示「搜索中…」；无结果显示「没有找到相关游戏」；失败显示错误框。

### 2. 价格详情与史低判定

点击搜索结果后展示价格卡片：

- ITAD 路径：原价、当前价（含折扣百分比）、Steam 史低（含日期）、全商店史低（含第三方商店）四个价格格子。
- CheapShark 路径：原价、当前价（优先 Steam 商店，无 Steam 价格时显示全网最低价并注明「非 Steam」）、历史最低（含日期），仅有美元。
- 判定结论（`computeVerdict`，当前价与史低对比）：

| 条件 | 结论文案 | 样式 |
|---|---|---|
| 史低为 0 且当前免费 | 现在免费，已是史低 | good |
| 史低为 0 但当前原价 | 史低是免费白嫖，现在原价，建议再等等 | bad |
| 当前价 < 史低 | 新史低！比历史最低还便宜 | good |
| 当前价 = 史低 | 已达史低，可以入手 | good |
| 高出史低 ≤ 10% | 接近史低（仅高 N%） | warn |
| 高出史低 > 10% | 高于史低 N%，建议再等等 | bad |

- 当前区域无该游戏价格数据时，显示空态说明而非报错。

### 3. 多区价格

- 支持 8 个区域：国区 (CNY)、美区 (USD)、香港 (HKD)、台湾 (TWD)、日本 (JPY)、英国 (GBP)、德国 (EUR)、巴西 (BRL)。
- 区域选择持久化在浏览器中，下次打开保持。
- 切换区域后隐藏已打开的详情卡片，并自动刷新愿望单价格。
- 未填 ITAD key 时区域选择被禁用并锁定为美区（CheapShark 只有美元价格）。

### 4. 本地愿望单

- 价格卡片上点「加入愿望单」把游戏加入列表；同一游戏（按数据源 + id 去重）重复加入不产生重复条目。
- 愿望单条目可单独移除。
- 「刷新价格」按钮批量重新拉取所有游戏价格，每条显示「现价 X / 原价 Y / 史低 Z」（无原价数据时省略原价段）和判定结论标签。
- 愿望单持久化在浏览器 localStorage，仅存于本机。

### 5. Steam 愿望单导入

- 愿望单区域点「导入 Steam 愿望单」打开 dialog，填入 Steam ID（17 位数字、`steamcommunity.com/id/xxx` 或 `/profiles/xxx` 链接）与 Steam Web API key，两者均持久化在 localStorage。
- 前提：愿望单已在 Steam 隐私设置中设为公开；已填写 ITAD key（导入需经 ITAD 把 Steam appid 映射为价格条目，未填则提示先设置）。
- 导入流程：经 serverless 中转读取 Steam 愿望单 → 逐个经 ITAD lookup 映射（并发 5，显示「正在匹配 n/m」进度）→ 按 ITAD id 去重合并入本地愿望单 → 自动刷新价格。
- 完成后显示摘要：新增 X 个、已存在 Y 个、ITAD 未收录 Z 个、匹配失败 W 个（可重试）。
- 错误提示：Steam ID 格式非法、key 无效、愿望单未公开、当前环境无 serverless 函数（本地静态服务器）等均有对应中文文案。

### 6. API Key 设置

- 右上角「API Key 设置」打开 dialog，粘贴 ITAD key 保存，或清除 key。
- key 只存浏览器 localStorage，不发送到 ITAD API 以外的任何地方。
- 填写/清除 key 后立即更新数据源提示文案和区域选择可用状态。

### 7. 错误与边界状态

- ITAD key 无效：显示「无法连接 ITAD / key 无效」类错误，并附「点右上角 API Key 设置检查」提示。
- ITAD 限流（HTTP 429）：提示请求太频繁，稍后再试。
- 网络失败（含被广告拦截插件拦截）：提示检查网络或插件。

## 非功能需求

- 以前端为主：无构建步骤、无账号体系；唯一例外是 Steam 愿望单导入依赖一个 Vercel serverless 中转函数（Steam 接口无 CORS 头，浏览器无法直连），部署到 Vercel 即可用，其余功能在任意静态托管上可用。
- 零依赖：不引入任何前端框架或第三方 JS 库。
- 所有动态渲染的用户/接口数据必须经过 HTML 转义（`esc()`），防 XSS。

## 非目标

- 不做价格提醒/通知（愿望单只有手动刷新）。
- 不做多设备同步（数据只在本机 localStorage）。
- 不展示历史价格曲线，只给当前价与史低的对比结论。
- 价格仅供参考，不替代商店页面（页脚已注明）。

## 验收标准

1. 不填 key：搜索 `Stardew Valley` 出结果，区域选择禁用且为美区，详情显示美元价格与判定结论。
2. 填入有效 ITAD key：数据源提示切换为 IsThereAnyDeal，区域可选择国区，详情显示人民币价格、Steam 史低和全商店史低三栏。
3. 填入无效 key：搜索给出 key 无效类错误提示。
4. 加入愿望单后刷新页面，愿望单仍在；点「刷新价格」各条目显示最新现价/原价/史低。
5. 切换区域后愿望单价格按新区域币种刷新。
6. 填入 Steam ID 与 Steam Web API key 导入公开愿望单：条目批量出现在本地愿望单并自动带出价格；愿望单未公开时给出「设为公开」提示。
